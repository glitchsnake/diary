# diary

Персональное десктопное приложение-дневник на **Python + PyQt5 + SQLite**.

## Возможности
- **Категории заметок:** структурирование записей по темам, создание новых категорий, переименование и удаление по правому клику мыши.
- **Хронология по дням:** удобный просмотр и фильтрация заметок по дням создания.
- **Автоматическая фиксация времени:** дата и точное время создания записи фиксируются автоматически без ручного выбора.
- **Фоновый учет времени письма:** приложение фоново считает время, проведенное за написанием каждой заметки и всего дневника в целом, не отвлекая тикающими таймерами.
- **Поиск:** мгновенная фильтрация по тексту и заголовкам.
- **Интерфейс:** минималистичная темная тема, карточки заметок, просторный ридер.

## Требования
- Python 3.8+
- PyQt5

Установка зависимостей:
```bash
pip install PyQt5
```

## Запуск приложения
```bash
python3 main.py
# или
./run.sh
```
